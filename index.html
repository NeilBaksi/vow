Build plan

A practical roadmap to launch

Phase 1
MVP marketplace + planning core

Auth, onboarding, supplier discovery, shortlist, budget, checklist, and the wedding dashboard.

Phase 2
Guest tools + website builder

RSVP flows, guest list, wedding website templates, and seating-chart logic.

Phase 3
Planner mode + AI concierge

Multi-client workspaces, supplier messaging, personalised recommendations, and smart task help.

Recommended stack

Next.js for the web app, Supabase for auth, database, and storage, Stripe for payments, and Mapbox or Google Maps for location-based discovery.

Design workflow

Brand direction → information architecture → wireframes → high-fidelity mockups → clickable prototype → production design system.

Go-to-market

Start with a curated set of Australian venues and suppliers in one city, prove the planning loop, then expand region by region.
